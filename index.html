THE METHOD

Deterministic enough to inspect. Rich enough to explore.

Each “run” feeds the case ID, model ID, run number, difficulty, and category through a small seeded function. That produces stable illustrative scores, consistency, and latency. Change a case or run again and the seed changes predictably.

score = seeded(case + model + run) × profile − difficulty
01 / DATA

Models, test prompts, and results are demo data. Custom cases remain in localStorage on this device.

03 / RUNS
